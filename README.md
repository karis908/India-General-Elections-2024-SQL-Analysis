# India General Elections 2024 – SQL Analysis

SQL Server project analyzing the India General Elections 2024 dataset.

## Tools
- Microsoft SQL Server
- SQL Server Management Studio (SSMS)
- SQL

## Analysis Covered
- Total election seats
- State-wise seat availability
- NDA and I.N.D.I.A alliance analysis
- Party-wise seats won
- State-wise alliance performance
- Winning candidates and victory margins
- EVM vs postal votes
- Top candidates by EVM votes
- Winner and runner-up analysis
- Maharashtra election summary

## SQL Concepts
SELECT, WHERE, GROUP BY, ORDER BY, JOIN, CASE WHEN, aggregate functions,
subqueries, ALTER TABLE, UPDATE, CTEs and window functions such as ROW_NUMBER().

## Folder Structure
- `SQL/` – SQL Server scripts
- `Documentation/` – project PDF/report
